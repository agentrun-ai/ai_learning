# AI搜学助手模板帮助文档

## 1. 模板概述

### 模板简介
AI搜学助手是基于 PydanticAI 框架构建的智能学习助手系统，能够自动收集、分析和总结网络学习资料，帮助用户快速理解和掌握各种知识概念。

### 适用场景
- 快速学习新概念和知识
- 整理和梳理学习资料
- 技术文档和教程收集
- 知识点深入理解和讲解
- 学习资源汇总

### 核心功能
- 自动化资料搜集与筛选
- 智能内容分析与分类
- 知识热度趋势分析
- 可视化知识讲解报告生成

## 2. 技术架构

### 使用框架
- **框架**：PydanticAI
- **Agent 类型**：单 Agent 架构
- **核心能力**：集成 LLM、搜索工具、Sandbox 环境

### Agent 架构说明
采用单 Agent 设计，该 Agent 具备多项能力：
- 信息检索能力（通过搜索工具）
- 数据分析能力（通过 Sandbox 环境）
- 自然语言理解与生成（通过 LLM）

### 技术要求
- 支持主流大语言模型（用户可自选）
- 需要配置搜索 API 访问权限
- 需要 Sandbox 环境支持

## 3. 功能说明

### 主要功能模块

**资料采集模块**
- 多源信息抓取（百科、知乎、B站、技术博客等）
- 关键词智能匹配
- 实时数据更新

**分析处理模块**
- 内容难度分析（入门/进阶/高级）
- 核心概念提取
- 知识结构梳理
- 学习价值评估

**报告生成模块**
- 结构化知识讲解文档
- 数据可视化图表
- 学习路径建议

### Agent 能力
1. **自主搜索**：根据关键词自动检索相关学习资料
2. **智能分析**：对海量资料进行内容分析和分类
3. **代码执行**：在 Sandbox 中执行数据处理和可视化代码
4. **报告生成**：自动生成通俗易懂的知识讲解报告

### 工作流程
```
用户输入概念 → Agent 执行搜索 → 资料收集 → 
内容清洗 → 知识分析 → Sandbox 数据处理 → 
生成可视化图表 → 输出知识讲解报告
```

## 4. 配置指南

### 在控制台配置

**模型配置**
- 在 AgentRun 控制台选择适合的大语言模型
- 建议使用支持长上下文的模型以处理大量学习资料
- 可根据分析精度需求选择不同参数的模型

**Sandbox 配置**
- 启用 Sandbox 环境
- 配置允许的 Python 库（如 pandas、matplotlib）
- 设置执行时间和资源限制

## 6. 常见问题

### Q1：搜索结果不准确怎么办？
- 在控制台优化搜索关键词设置
- 调整搜索范围和时间窗口
- 增加搜索深度获取更多结果

### Q2：分析速度较慢？
- 选择更高性能的模型
- 减少搜索结果数量
- 使用快速分析模式

### Q3：如何提高分析准确度？
- 选择专门针对知识理解优化的模型
- 调整内容相关性阈值
- 启用深度分析模式

### 注意事项
1. **内容版权**：收集的资料仅供学习参考，请尊重原创内容版权
2. **搜索配额**：注意搜索 API 的调用限制
3. **结果时效性**：部分技术内容会随时间更新，建议关注最新资料
4. **模型选择**：不同模型对中文理解能力差异较大，建议测试后选择
5. **可视化限制**：Sandbox 中的图表生成受资源限制，避免处理超大数据集
